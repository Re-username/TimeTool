# TimeTool + Rainmeter

Пока TimeTool запущен (в том числе свёрнут в трей), он поднимает локальный сервер на `http://127.0.0.1:47777/` (только localhost, наружу не светится; если порт занят — пробует следующие до 47786).

## Эндпоинты

| Путь | Формат | Для чего |
|---|---|---|
| `/` | HTML | встраивание целиком (плагин WebView2), автообновление 1 раз/сек |
| `/events.json` | JSON | массив `{Name, Next, DaysLeft, Left, Repeat, WeekendShift}` |
| `/events.txt` | текст `имя\|дд.мм.гггг чч:мм\|осталось` | встроенный плагин WebParser |

## Вариант 1: WebParser (без сторонних плагинов)

Скопируйте папку `TimeTool-WebParser` в `Документы\Rainmeter\Skins`, в Manage Rainmeter нажмите Refresh All и загрузите скин. До 4 событий, обновление раз в секунду.

## Вариант 2: WebView2 (красивее — вся страница внутри скина)

Нужен плагин [WebView2 для Rainmeter](https://github.com/NSTechBytes/WebView2): скачайте `WebView2.dll` из его релизов и положите в папку скина `TimeTool-WebView2`. Скопируйте папку в Skins, Refresh All, загрузите скин. Размер меняется переменными `#W#`/`#H#` в начале .ini.

## Проверка вручную

Откройте в браузере http://127.0.0.1:47777/ — должна быть страница с отсчётами. Если страница не открывается, смотрите `%LOCALAPPDATA%\TimeTool\tray.log` (строка `rainmeter: сервер запущен…`).

> Примечание про кодировку: Rainmeter надёжнее всего читает скины в UTF-16 LE (с BOM).
> Если русские строки отображаются крякозяброй — пересохраните .ini в UTF-16.
